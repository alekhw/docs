## Current Runtime Features

- root-routed documentation pages
- search endpoint from Fumadocs source
- `llms.txt` and `llms-full.txt` export routes

## Navigation and branding

The desktop sidebar and mobile menu provide icon links to the Everstrat website,
application, and GitHub organization. The header uses the same EVER / STRAT
wordmark and symbol as the application, with a Docs label and a white mark in dark mode.

`NEXT_PUBLIC_WEBSITE_URL` and `NEXT_PUBLIC_APP_URL` override the website and application
destinations. When omitted, the links use the official URLs listed in
[Links & support](/reference/network-and-links).

## Current Ask AI Decision

The interactive Ask AI chat is disabled. The docs app still exposes `llms.txt`,
`llms-full.txt`, and page-level Markdown exports for external tooling and AI consumers.
