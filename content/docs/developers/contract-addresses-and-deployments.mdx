## Canonical snapshot

The primary developer snapshot lives in:

- `frontend-app/web3-app/src/config/index.ts` — `CONFIG.CONTRACTS`
- `frontend-app/web3-app/subgraph/config/deployments/sepolia.json` — the deployment config the subgraph regenerates from

The subgraph's `src/config.ts` is auto-generated from `sepolia.json` by `scripts/sync-config.mjs`. All three files agree exactly.
