## What Is Not Trustless

- queue pricing cadence
- strategy distribution and withdrawal operations
- oracle feed configuration
- subgraph freshness

## What Is More Rigid

- ERC-20 token behavior in `EVE`
- AMM core deposit and exit entry points
- queue escape-hatch timing once encoded in `ExitQueue`
