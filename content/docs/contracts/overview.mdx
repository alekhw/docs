## Contract map

| Component | Deployment model | Primary responsibility |
| --- | --- | --- |
| Registry | Static, configurable | Registered peer addresses, roles, pause of its own guarded mutations |
| EVE | Immutable | ERC-20 protocol shares |
| AMM | Immutable, configurable | Mint, redeem, escrow, and claims |
| Whitelist | Static, configurable | Invite entry authorization |
| Controller | UUPS proxy | Strategy and queue coordination |
| ExitQueue | UUPS proxy | Batch/request metadata and redemption offsets |
| StrategyManager | UUPS proxy | Strategy registry, allocation weights, NAV, performance fees |
| Oracle | UUPS proxy | Token feed registration and valuation |
| Converter | UUPS proxy | Supported conversion routes and adapters |
| Converter adapters | Separate contracts | Execute approved conversion routes |
| UniCL strategies | Separate immutable instances | Manage Uniswap v3 liquidity positions |
| QueueKeeperExecutor | Static, configurable | Authenticated queue operations |
| StrategyKeeperExecutor | Static, configurable | Authenticated strategy operations |
| Timelock | Separate governance contract | Delayed ADMIN execution |

Pause controls are per contract; Registry pause is not a shared global pause.
Immutable code does not mean immutable configuration or immutable dependencies.
Existing UniCL strategies are replaced through registration and removal, not proxy upgrades.
