## Documentation Boundary

This docs app does not own protocol logic or frontend logic, but it must remain aligned with them.
That means the docs source of truth is spread across:

- `smart-contracts/README.md`
- `frontend-app/web3-app/README.md`
- `frontend-app/web3-app/src/config/index.ts`
- `frontend-app/web3-app/subgraph/*`
- `mermaid/*.md`
