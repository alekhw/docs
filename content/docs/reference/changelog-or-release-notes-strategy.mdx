---
title: Changelog or release notes strategy
description: Recommended strategy for documenting deployment and docs changes over time.
---

## Recommended Strategy

Keep changelog records near the surfaces that actually change:

- contract deployment changes in `operations`
- frontend behavior changes in `app`
- data model or endpoint changes in `data`

## Minimum Useful Entry

Each release note should record:

- date
- changed workspace
- changed addresses, endpoints, or UX behavior
- whether docs were updated in the same change set
