## Reporting issues

Because Everstrat is in a testing phase, there is no formal support process. If you encounter a bug or
unexpected behaviour, check the [FAQ](/reference/faq) first. For contract-level questions, the source
code is available in the GitHub repository ([`everstrat-xyz/contracts`](https://github.com/everstrat-xyz/contracts)).
