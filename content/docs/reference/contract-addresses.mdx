## Ethereum mainnet (chain ID 1)

The canonical [current deployment snapshot](/operations/current-deployments) lists the
registered core contracts, keeper executors, live settings, and registered strategies.
The official EVE token is
[`0x8FE6A43672fCa70d41e112B8426387665fD061EC`](https://etherscan.io/address/0x8FE6A43672fCa70d41e112B8426387665fD061EC).

The dated snapshot records the registered strategy basket and migration operation states.
Controller 1.1.0 is active after 018; 019/020 are scheduled, not a completed v2 migration.
Recheck the snapshot and `StrategyManager.strategies()` as those operations execute.
Do not use the old "no mainnet strategies" or bootstrap-supply description to assess the deployment.

## Verification

Read Registry's registered keys and StrategyManager's strategy list at a pinned block,
then compare the intended network, explorer code, and transaction target.
Controller, StrategyManager, Oracle, ExitQueue, and Converter are listed at their proxy
addresses. Changing implementation does not change the address integrations call.

App configuration lives in `everstrat-xyz/app`, particularly
`src/config/index.ts` and `subgraph/config/deployments/mainnet.json`.
Configuration describes intended integration targets; current on-chain registration
and execution receipts establish deployed state.
