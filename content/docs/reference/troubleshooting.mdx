## Common Issues

<Accordions type="single">
  <Accordion title="My wallet connects but transactions do not start">
    Check that you are on Ethereum mainnet and that the wallet flow completed the required network switch.
  </Accordion>
  <Accordion title="My burn is still pending">
    If the request was queued, it depends on batch pricing and processing. Check whether cancellation is available.
  </Accordion>
  <Accordion title="The activity feed is incomplete">
    Verify the GoldSky endpoint and allow for indexing delay. The frontend uses direct RPC only for a subset of current state.
  </Accordion>
</Accordions>
