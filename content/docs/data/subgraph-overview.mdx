See the [subgraph and RPC data-flow diagram](/developers/subgraph-and-data-access#everstrat-data-diagram) for how consumers read protocol data.

## What the subgraph exists to do

- index successful user actions initiated from the web3 app
- track keeper-driven queue state transitions that happen after the user transaction
- serve account profile data and activity history to the frontend

## Mandatory indexed contracts

- `AMM`
- `ExitQueue`
- `EVE`

## Current deployment target

The repository targets **Ethereum mainnet** (chain id `1`). The current public endpoint is the
GoldSky deployment at:

`https://api.goldsky.com/api/public/project_cm7aaq2gvh5ak01wf890nferb/subgraphs/everything-strategy-mainnet/prod/gn`

Source of truth: `frontend-app/web3-app/src/config/index.ts` (`CONFIG.SUBGRAPH_URL`) and
`frontend-app/web3-app/subgraph/config/deployments/mainnet.json`. For the full deployment
details see [Subgraph deployments](/operations/subgraph-deployments).
