## Legacy history

`Guide-DAO-Organization/hackerhouse` contains the source history preceding extraction.
It is private and requires repository access, so it is not a public contributor entry point. Old references to
`frontend-app/web3-app`, `frontend-app/landing`, and `frontend-app/everstrat-docs`
are historical paths, not the current standalone checkout layout.

The docs route retains its old `monorepo-structure` slug for link compatibility.

## Evidence hierarchy

Use deployed code and pinned chain reads for live behavior, contracts source and tests
for implementation, app source for UI behavior, and governance payloads for proposed changes.
Keep proposals separate from execution receipts; repository main can be ahead of deployed code.
