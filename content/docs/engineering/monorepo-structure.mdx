## Main Workspaces

- `frontend-app/landing`
- `frontend-app/web3-app`
- `frontend-app/web3-app/subgraph`
- `frontend-app/everstrat-docs`
- `smart-contracts`
- `mermaid`

## Why This Matters

Documentation is distributed across these workspaces. There is no single standalone “docs truth”
directory outside the docs app itself.
