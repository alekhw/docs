## Ownership Summary

| Workspace | Owns |
| --- | --- |
| `landing` | brand, positioning, user-facing copy tone |
| `web3-app` | shipped user behavior |
| `subgraph` | indexed data model and deployment config |
| `smart-contracts` | protocol semantics and role model |
| `everstrat-docs` | public explanation and navigation |

## Rule

Docs should explain, not replace, those ownership boundaries.
